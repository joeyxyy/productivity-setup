# Productivity Setup v0.2.0

Desktop update with sound cues.

## What's New

- Added calm sound cues for Sit, Stand, and Walk transitions.
- Added sound cues for eye break and stretch reminders.
- Sound cues follow the existing Sound setting, so they can be turned off in Settings.
- Updated the Windows desktop build.

## Local Download

The packaged desktop app zip is created at:

```txt
release/Productivity-Setup-Desktop-v0.2.0.zip
```

Unzip it, then run:

```txt
Productivity Setup.exe
```
